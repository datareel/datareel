DataReel 6.4.2 Release Notes, 11/20/2026
DataReel version 6.4.2 (was 6.4.1)
DataReel Copyright (c) 2001-2026 DataReel Software Development

DataReel 6.4.2 is a maintenance release of the 6.4 legacy line:
license headers, documentation and AI-assisted development files. No
library code changed: the API, the database file format and the
gxStream wire format are those of 6.4.1, and everything in
RELEASE_NOTES_6.4.1.txt is included. Version 6 is the legacy line: it
gets bug fixes and security updates, but no new features. The shared
library (Linux makefiles) is built as libdatareel.so.6.4.2.

CHANGES
-------
- License: every source header says LGPL version 3 or later, matching
  LICENSE (some still named an older version).
- AI-assisted development: AGENTS.md, CLAUDE.md and GEMINI.md for the
  legacy release, with the AI usage policy (written management
  approval, approved enterprise AI models only) and the human-in-the-
  loop rules.
- Documentation: docs/security_white_paper.md (.html), the security
  design of the library; docs/gxstream_replication_white_paper.md
  (.html), gxStream, gxDatagram and replication on port 2073
  (gxs-data-port, registered with IANA); docs/rfc/
  draft-gaer-datareel-gxstream-00, the protocol's specification (an
  Internet-Draft for the Independent Submission stream that covers
  DataReel 7.4 and the 6.x legacy transports).
- Documentation: the example pages escape the license URL, so browsers
  show it.
- Comments and documentation no longer include personal names or email
  addresses (gxsIMAPClient).
