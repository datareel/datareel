Building and Running

Each example program is in its own folder under examples_database, examples_general, examples_socket and examples_threads. The programs test one part of the library each and can be used as templates for new applications. The listings in the menu on the left are older programs kept for reference; the programs below are the ones built and tested with this release.

To build and run an example on Linux:

cd datareel/env
source gnu_env.sh
cd ../examples_database/simple
make
./testprog

On Windows use nmake -f msvc.mak in the same folder. The SSL examples (https_client, ssl_server and ssl_verify_cert) need the library built with OpenSSL; see Linux Builds. Most test programs pause between steps and wait for Enter. string_class can be built with -D__AUTORUN_TESTPROG__ to run without prompts. All of these programs were run under AddressSanitizer and UndefinedBehaviorSanitizer for the 10/14/2026 code review.
