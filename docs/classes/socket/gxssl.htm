Overview

The gxSSL class is an OpenSSL wrapper used to add SSL/TLS encryption to client and server socket applications. A gxSSL object holds the OpenSSL context object, the SSL object and the BIO objects used for socket I/O, and provides functions to load certificates and keys, perform the handshake, send and receive data, verify peer certificates and generate RSA keys, self-signed certificates and Diffie-Hellman parameters.

gxSSL works with any connected socket, such as a gxSocket object. The socket is opened and connected or accepted as usual and then passed to OpenSSLSocket(). Some of the class functions were derived from "SSL and TLS: Designing and Building Secure Systems" by Eric Rescorla (Addison Wesley, 2001) and from the OpenSSL documentation and example programs.

The include file also defines the gxRandom class, a pseudo random number table generator used internally by gxSSL. See gxRandom Class.

Conditional Directives

__USE_GX_SSL_EXTENSIONS__ - Conditional directive required to build the gxSSL class. Without it only the gxRandom class is compiled.

__WIN32__ - Conditional directive required for all WIN32 platforms

__UNIX__ - Conditional directive required for all UNIX variants.

__LINUX__ - Conditional directive required for all Linux platforms.

Building and Requirements

gxSSL is built into the library. On Linux it uses the OpenSSL that comes with the operating system (OpenSSL 3 on RHEL 8, 9 and 10). The code selects the OpenSSL interfaces from OPENSSL_VERSION_NUMBER, so no other settings are needed. On Windows it uses the native Schannel (SSPI) TLS API by default, with OpenSSL as an option. Windows OpenSSL builds must use only an OpenSSL 3.5.x LTS release, 64-bit by default and 32-bit for legacy builds only (see README_windows_openssl.txt).

Linux library build (SSL is on by default):

cd build
make

Linux applications are compiled with -D__USE_GX_SSL_EXTENSIONS__ and linked with -lssl -lcrypto.

Windows applications built with the default Schannel library are compiled with -D__USE_GX_SSL_EXTENSIONS__ -D__USE_GX_SCHANNEL__ and linked with secur32.lib crypt32.lib ncrypt.lib. Build the library and programs with USESSL=1 to use OpenSSL 3.5.x LTS instead. For Windows builds see the Windows Builds section of the readme.

Schannel notes: GetCTX() and GetSSL() return Schannel objects, not OpenSSL SSL_CTX and SSL pointers, so code that calls OpenSSL functions directly must use the OpenSSL build. Use GetPeerCertInfo(), VerifyCert() and CertVerifyErrorString() for portable cert checks. A server can load PEM or DER cert and key files with InitCTX(), or a PFX/P12 file with the key password. Call SetHostName() before ConnectSSLSocket() to send the server name (SNI); gxsHTTPClient does this for you. The key and cert generator functions MakeDHParms(), MakeRSAPrivateKey() and MakeCertReq() need OpenSSL and return an error in the Schannel build. Create keys and certs with the openssl command line tool or the Windows certificate tools.

__USE_GX_SCHANNEL__ - Windows only. Builds gxSSL with the native Schannel API instead of OpenSSL. Set by default in the Windows makefiles.

Newer OpenSSL versions no longer support SSLv2 and SSLv3. With OpenSSL 1.1.0 and later gxSSL_SSLv2 and gxSSL_SSLv3 select the version flexible method. Use gxSSL_TLS for new applications; it negotiates the highest TLS version supported by both sides.

int gxSSL::LoadDHParms(const char *fname)

Public member function used to load Diffie-Hellman parameters from the fname PEM file into the SSL context object for DHE cipher suites. The context must be created with InitCTX() first. With OpenSSL 3 the parameters are read with PEM_read_bio_Parameters() and set with SSL_CTX_set0_tmp_dh_pkey(). OpenSSL 3 rejects parameters smaller than 2048 bits at its default security level. Returns 0 if successful or a non-zero gxSSLError code if an error occurs. NOTE: 10/14/2026: Errors setting the parameters are now reported. Earlier versions missed the OpenSSL 1.x failure value of 0.

int gxSSL::MakeCertReq(const char *key_fname, gxCertIssuerInfo &ci, const char *req_fname)

Public member function used to write a self-signed X509 certificate for the private key in key_fname to the req_fname file. The ci variable sets the subject and issuer fields, serial number, days to expire and certificate extensions. See gxCertIssuerInfo. Returns 0 if successful or a non-zero gxSSLError code if an error occurs.

int gxSSL::MakeClient()

Public member function used to configure this object for client connections. Call before InitCTX().

int gxSSL::MakeDHParms(const char *dh_fname, unsigned char *dh1024_p = 0, int dh1024_p_len = 0, unsigned char *dh1024_g = 0, int dh1024_g_len = 0)

Public member function used to write Diffie-Hellman parameters to the dh_fname file in PEM format. The prime and generator are passed as big-endian byte arrays in dh1024_p and dh1024_g. If they are not specified the RFC 7919 ffdhe2048 group (2048-bit prime, generator 2) is written. The parameter names are kept for compatibility; primes of any length can be passed. Returns 0 if successful or a non-zero gxSSLError code if an error occurs. NOTE: 10/14/2026: The default group was a 1024-bit prime, which OpenSSL 3 rejects ("dh key too small") and which is too weak to use.

int gxSSL::MakeRSAEphKey(int key_len = 512)

Public member function used to set a temporary RSA key for export cipher suites. With OpenSSL 1.1.0 and later temporary RSA keys are not supported and this function does nothing and returns 0.

int gxSSL::MakeRSAPrivateKey(const char *key_fname, int key_len = 512, KeyGenCallbackFunc cb_func = 0, void *cb_arg = 0)

Public member function used to generate an RSA private key of key_len bits and write it to the key_fname file in PEM format. The optional cb_func callback is called with cb_arg during key generation to report progress. The pseudo random number generator is seeded before the key is generated. Use a key_len of 2048 or more; the 512-bit default is kept for compatibility only. Returns 0 if successful or a non-zero gxSSLError code if an error occurs.

gxRandom Class

The gxRandom class generates tables of pseudo random numbers and seeds. It is used internally by gxSSL and does not require OpenSSL. It is not a cryptographic random number generator; use InitPRNG() and the OpenSSL generator for keys and other secrets.

openssl.SetSSLProto(gxSSL_TLS);
openssl.SetCertFile("server_cert.pem");
openssl.SetKeyFile("server_private_key.pem");
if(!openssl.InitCTX()) {
  cerr << openssl.SSLExceptionMessage() << "\n";
  return 1;
}
openssl.LoadDHParms("dhparms.pem"); // Optional, enables DHE cipher suites

// remote_socket was accepted by a gxSocket server
if(openssl.OpenSSLSocket(remote_socket) != 0 ||
   openssl.AcceptSSLSocket() != 0) {
  cerr << openssl.SSLExceptionMessage() << "\n";
  return 1;
}
char buf[255];
int bytes = openssl.RawReadSSLSocket(buf, sizeof(buf));
openssl.SendSSLSocket(buf, bytes); // Echo the data back
openssl.CloseSSLSocket();

10/14/2026 Changes

The gxSSL code was reviewed and fixed by Claude Code, Anthropic's AI coding assistant (https://claude.ai/code), in the 10/14/2026 code review. Summary of the gxSSL changes:

  • OpenSSL 3 interfaces for Diffie-Hellman parameters (OSSL_PARAM_BLD, EVP_PKEY_fromdata(), PEM_write_bio_Parameters(), PEM_read_bio_Parameters(), SSL_CTX_set0_tmp_dh_pkey()) and RSA keys (EVP_PKEY_CTX_new_from_name()). The OpenSSL 1.1 and older code paths are kept.
  • MakeDHParms() writes the RFC 7919 ffdhe2048 group by default instead of a 1024-bit prime.
  • LoadDHParms() reports errors setting the parameters and checks for a null context object.
  • MakeRSAPrivateKey() seeds the random number generator first, generates the key before opening the key file and frees everything on every path.
  • MakeRSAEphKey() does nothing with OpenSSL 1.1.0 and later.
  • MakeCertReq(): fixed an undefined order of evaluation in the X509_new() call.
  • Release() added; Relase() now clears all of the BIO pointers.
  • The gxRandom tables are freed with delete[].
  • The ssl_server example has a new 2048-bit key, certificate and DH parameter file.

See Code Review and Fixes for the full list of library changes.
