Overview

The gxIP32 class is used by database applications to represent 32-bit Internet protocol addresses independently of the operating system or hardware platform used.

Public member function that passes back a null terminated IP32 string in the "sbuf" variable and redundantly return the string. NOTE: The calling function must allocate a memory buffer large enough to hold a single IP32 string in dotted notation: 127.0.0.1
