Page Cache (gxdPageCache)

Overview

gxdPageCache (gxdpcache.h, new in 6.3) caches 4 KB file pages for a gxDatabase (gxDatabase::EnablePageCache()) and holds the pages of open journal transactions. With use_map = 1 pages not in the cache are read from a read-only memory map of the file (off by default in 6.3, on by default in DataReel 7.3). Most programs use it through gxDatabase and gxdJournal.
